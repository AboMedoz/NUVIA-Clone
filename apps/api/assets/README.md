# Report font

`NotoSansArabic.ttf` is the complete Noto Sans Arabic variable font from the official Google Fonts repository, including Arabic, Latin, digits and punctuation. The full font prevents missing glyphs in mixed EN/AR report lines. It is embedded/subset by PDFKit/fontkit at export time. `NOTO-LICENSE.txt` accompanies redistribution under SIL OFL 1.1.
