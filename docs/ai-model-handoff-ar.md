# مودلز NUVIA المطلوبة من التيم

كل ميزة لا تحتاج موديلًا منفصلًا. يمكن مشاركة نفس الأوزان بين عدة قدرات، لكن
كل قدرة لها حزمة/عقد ومدخلات ومخرجات واختبار قبول مستقل. التدريب والتقييم
العلمي من التيم؛ الربط البرمجي لا يثبت جودة الموديل.

| المهمة                    | ما يحتاجه التيم                          | شكل القبول الوظيفي                                                       |
| ------------------------- | ---------------------------------------- | ------------------------------------------------------------------------ |
| انطباع الرد والجمل        | مصنّف عربي/إنجليزي/مختلط                 | أربع فئات، تغطية كل الجمل، إصدار الموديل، لا ثقة مخترعة                  |
| استخراج الجوانب وانطباعها | ABSA بتصنيف جوانب versioned              | جانب + انطباع + معرّف جملة + اقتباس/موقع مطابق للأصل                     |
| بحث دلالي واسترجاع        | Embeddings متعدد اللغات                  | متجه لكل معرّف نص، أبعاد ثابتة وقيم محدودة وصالحة                        |
| تجميع شكاوى               | Embeddings وخوارزمية تجميع               | عضوية مجموعات/ضوضاء مرتبطة بمعرّفات الأدلة الصحيحة                       |
| ملخص المجموعة             | موديل توليدي؛ يمكن مشاركة موديل التقارير | ملخص مبني على ردود المجموعة واقتباسات فعلية                              |
| تقارير وتوصيات            | موديل توليدي عربي/إنجليزي                | أقسام تستند إلى snapshot مصرح به واقتباسات متحققة                        |
| مساعد                     | موديل توليدي مع استرجاع                  | إجابة بأدلة أو حالة صريحة بأن الأدلة لا تكفي                             |
| اقتراح استبيان            | موديل توليدي                             | 5–10 أسئلة قابلة للتعديل، لا نشر تلقائي                                  |
| تطبيع إملاء/لهجات متقدم   | حزمة normalization متخصصة أو توليدية     | النص الأصلي محفوظ، مع إعلان مهام الحزمة وعدم ادعاء تغطية لهجات غير مقيمة |
| توقع الرضا                | نموذج إحصائي/تعلم آلي على تاريخ كافٍ     | تواريخ أفق مستقبلية وعدم يقين وحجم عينة؛ مقارنة baseline لاحقًا          |

التطبيع العربي الأساسي وتقسيم الجمل والحسابات والفلاتر والرسوم وCSV/PDF
لا تحتاج أوزانًا مستقلة. درجات الجوانب والرسوم تستخدم نتائج التحليل المحفوظة
حين تتوفر، ولا تملأ النتائج الغائبة بأرقام معاينة.

## Qwen الموجود محليًا

اختُبر لاستخدام **اقتراح مسودات استبيان** قابلة للمراجعة فقط، وبقي **غير مفعّل**
بعد فشل قبول المسودات الإنجليزية/العربية بصورة موثوقة. لا
تعتمدوه تلقائيًا للانطباع أو ABSA اعتمادًا على وجوده أو نجاح تحميله. التقرير
التجريبي المحلي السابق لا يحقق أهداف جودة التحليل؛ قبول أي استخدام جديد
يحتاج مخرجات فعلية وتقييمًا مناسبًا لذلك الاستخدام. النتيجة موثقة في
[تقرير التجربة المحلية](../apps/ai-service/docs/qwen-local-trial.md).
نجاح تحميله على CUDA لم يتحول إلى ادعاء بجودة مخرجاته، ولا يوجد تفعيل افتراضي.

البحث والمقارنة على Colab لهما [تقرير منفصل](model-research/README.md) يفرّق بين
أحجام الملفات، وذاكرة التشغيل، والقياسات الحالية، وأرقام ناشري المودلز.

## تسليم الحزم للربط

راجعوا [دليل حزم المودلز](../apps/ai-service/docs/model-packages.md) و[العقود](../apps/ai-service/docs/contracts.md).
يتضمن التسليم manifest، والقدرة واللغة والتصنيف والإصدار والجهاز، والملفات
بصيغ adapter مدعوم وبصمات SHA256. مجرد ملف أوزان عشوائي أو LoRA/GGUF غير
مدعوم لا يتفعل تلقائيًا. نماذج manifest وطلبات smoke موجودة في
`apps/ai-service/examples/` ولا تتضمن أوزانًا أو نتائج منتج وهمية.

ابدؤوا بمصنّف انطباع، وموديل جوانب، وEmbeddings، وموديل توليدي، مع محاولة
دمج المهام عندما يثبت التقييم جدواها. لا يلزم تدريب أربعة مودلز من الصفر؛
الاختيار وإعادة الاستخدام يعتمدان على اللغة والترخيص وجودة التقييم والصيغة.
